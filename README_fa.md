# 🍎 Fruit Catcher

🍎 Fruit Catcher — یک بازی HTML5 مدرن و بدون وابستگی، ساخته‌شده با Canvas و جاوااسکریپت خالص.

🎮 **بازی آنلاین:** https://gamelabz.github.io/html5-game-fruit-catcher/

## 📸 تصویر بازی

![Fruit Catcher](assets/images/screenshot.png)

## 🎯 درباره بازی

سبدت را حرکت بده تا میوه‌های در حال سقوط را بگیری و با دوری از میوه‌های فاسد امتیاز بسازی.

## 🕹️ کنترل‌ها

- حرکت: موس / کلیدهای جهت‌دار
- توقف موقت: P
- شروع دوباره: R

## ✨ ویژگی‌ها

- میوه‌های در حال سقوط با گرانش
- آیتم‌های خوب در برابر بد
- امتیاز کمبو

## 🚀 اجرا در محیط محلی

نصبی لازم نیست. بازی را مستقیماً در مرورگر باز کن:

```bash
# روش اول: باز کردن مستقیم فایل
open index.html

# روش دوم: سرویس با یک سرور استاتیک کوچک
npx serve .
```

سپس به نشانی چاپ‌شده مراجعه کن (پیش‌فرض `http://localhost:3000`).

## 🛠️ تکنولوژی

- HTML5 `<canvas>`
- CSS3 (متغیرهای سفارشی، flexbox، گلس‌مورفیسم)
- جاوااسکریپت خالص (ES2020، بدون فریم‌ورک)
