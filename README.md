# 🍎 Fruit Catcher

🍎 Fruit Catcher — a modern, dependency-free HTML5 game built with Canvas and vanilla JavaScript.

🎮 **Play Online:** https://gamelabz.github.io/html5-game-fruit-catcher/

## 📸 Screenshot

![Fruit Catcher](assets/images/screenshot.png)

## 🎯 About

Move your basket to catch the falling fruit and build combos while avoiding the rotten ones.

## 🕹️ Controls

- Move: Mouse / Arrow keys
- Pause: P
- Restart: R

## ✨ Features

- Falling fruit with gravity
- Good vs bad items
- Combo scoring

## 🚀 Run Locally

No installation required. Open the game directly in a browser:

```bash
# Option A: just open the file
open index.html

# Option B: serve it with a tiny static server
npx serve .
```

Then visit the printed URL (default `http://localhost:3000`).

## 🛠️ Tech Stack

- HTML5 `<canvas>`
- CSS3 (custom properties, flexbox, glassmorphism)
- Vanilla JavaScript (ES2020, no frameworks)
